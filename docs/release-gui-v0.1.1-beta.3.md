# 日志台 0.1.1-beta.3 — 基线 / 阶段甘特 / 磁盘占用 / 深链

> 完整变更记录见 [CHANGELOG](../CHANGELOG.md)；功能文档见 [docs/gui-log-viewer.md](gui-log-viewer.md)。

这是 0.1.1 线的**第三个（最后一个）预发布版**，交付「洞察」计划的第三批：**A5 基线漂移视图、A6 状态跃迁甘特、
A9 产物磁盘占用统计、A8b 深链 `tianshu://task/<id>`**。前三项仍是只读增强；A8b 是本轮唯一需要
**新增 Tauri 插件与协议注册**的系统集成项（含降级预案）。

---

## 本次新增

### A5 工作区新增「基线」分区

- 展示该任务派单时保存的 `baseline.json` 摘要：是否版本库 / HEAD（短哈希）/ 动工前是否已脏 /
  动工前已有改动数 / 未跟踪文件数 / 采集时间与说明；
- **与最新报告对照**：报告中本次实际改动（文件数、`+N / -M`）与基线里的「已有改动」并排，用于判断改动是否越界；
- **没有基线就如实说**：缺失或损坏一律提示「该任务没有保存的动工前基线」，**不编造零值**。

### A6 事件流新增「阶段」视图（状态跃迁甘特）

- 事件流工具栏新增 **列表 / 阶段** 分段切换：列表仍是原来的尾部窗口（大文件友好），
  阶段视图**按需读一次全量** `task.jsonl`；
- 阶段 = **相邻两次状态跃迁之间**（`created → started → verify_start → fix_start → … → succeeded/failed`），
  横向条宽按占阶段总时长的比例绘制（纯 div，不引图表库）；
- 最后一段没有结束时间时标 **「进行中」并用斜纹区分**——**不编造时长**；
- 全量读取后若开头仍不是 `created`（文件被截断），页面**如实提示**阶段视图可能不完整；
- `full` 缺省为 `false`：列表视图行为与之前**逐字节一致**（不回归）。

### A9 洞察页新增「磁盘占用」分区

- 总量 / 任务产物 / `logs/` 体积与占比 / 任务体积中位数 / 体积 TOP 20 表（含「体积大户」=任务内最大文件及其占比）；
- **「可清理」提示**：判据全部是**相对口径**（单个文件占该任务 **> 50%**，或该任务体积 **≥ 全部任务体积中位数的 2 倍**），
  两个比例是 `core/insights.ts` 顶部**具名常量**，不散落在组件里、也不写死绝对字节阈值；
- **只统计不删除**：本页与后端命令**不提供任何删除 / 清理入口**，只 `stat` 文件、不读内容；
- 口径说明：磁盘占用按**实测目录**统计（`logs/` + `tasks/` 下**所有**子目录），**不按 `tsk_` / `vfy_` 前缀过滤**
  ——与「任务列表」的扫描口径**有意不同**，因为过滤前缀会把真实占盘算漏；界面已标注。

### A8b 深链 `tianshu://task/<任务ID>`

- **冷启动与热启动都支持**：启动参数或已运行实例收到的深链会进入 Rust 侧队列并发出 `gui://deeplink` 信号，
  前端**取走队列**后解析路由（冷启动时事件早于前端监听，故**队列才是事实来源**，不会丢链接）；
- **单实例**：第二次启动不再新开窗口，而是**唤出已有窗口**并把 URL 转给首实例（`single-instance` 插件，
  启用其 `deep-link` feature，URL 参数自动转发）；
- **协议注册**：启动时注册 `tianshu` 协议处理器；**注册失败不阻塞启动**（macOS 返回 `UnsupportedPlatform` 属预期）；
- **解析在纯函数里**：只接受 `tianshu://task/<id>`，任务 ID 走字符白名单 `[A-Za-z0-9_-]`（深链是外部输入，
  ID 会拼进文件路径）；含 `..` / `%2e` 的写法**直接拒绝**（URL 归一化会把 `..` 消掉，归一化后就再也看不出原样，
  与其静默猜成另一个 ID，不如如实判为无法识别）；无法识别的链接在界面上**如实提示**，不静默丢弃。
- **权限口径（最小化）**：深链**全部在 Rust 侧处理**，前端不调用 `@tauri-apps/plugin-deep-link` 的 JS API，
  因此 `capabilities/default.json` **不新增 `deep-link:default`**——不给 webview 任何多余的插件能力。
- **降级预案**：若某平台冷启动路由不通，保留热启动路径（`on_open_url`）并在 `docs/gui-log-viewer.md` 中如实说明平台差异，
  不影响本批其它功能。

## 口径说明

- **基线 / 磁盘 / 全量事件全部只读**：不写任何业务数据；本版新增的两个 Rust 命令只读文件与 `stat`。
- **缺失一律如实留空**：没有基线显示「没有基线」，读不到报告显示不可用，时间不可解析显示 `—`，**不编造**。
- **甘特不做归一化**：各阶段时长之和即「阶段合计」；有阶段不可解析时该段显示「进行中」，不参与合计。

## 边界（本批次没做什么）

- 三个批次（A1–A9）至此**全部交付**；本版之后 `0.1.1` 线可择期转正为 `0.1.1`（由维护者决定）；
- 不提供任何**写操作**：没有清理 / 删除入口，没有任务续跑与返修；
- 不做通知 / 托盘角标，不做本地全文索引，不做实时监听洞察数据（沿用既有决策）。
