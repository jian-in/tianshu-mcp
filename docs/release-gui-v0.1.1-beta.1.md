# 日志台 0.1.1-beta.1 — 洞察（效能看板 / 失败归因 / 时间趋势）

> 完整变更记录见 [CHANGELOG](../CHANGELOG.md)；功能文档见 [docs/gui-log-viewer.md](gui-log-viewer.md)。

这是 0.1.1 线的**第一个预发布版**，交付「洞察」能力的前三项：**A1 效能看板、A2 失败归因、A3 时间趋势**，
并为它们新增一条**只读**聚合取数通道。

---

## 本次新增

### 侧栏「洞察」入口

主导航在「任务列表」之后新增**「洞察」**整页（`view` 由三态扩为四态）。页面分三个分区，用分段控件切换：

| 分区 | 内容 |
|---|---|
| 效能看板 | 按 **Agent** 与按 **项目** 两张表：任务数 / 成功率 / 平均轮次 / 一次通过率 / 平均验收耗时 / 报告缺失数 |
| 失败归因 | 四类归因的 TOP 列表（错误类型 `errorType` / 失败检查项 `failedCheck` / 阻塞问题 `blockingIssue` / 代码信号 `signal`），带占比条 |
| 时间趋势 | **按天 / 按周**切换；任务量柱状 + 成功率与返修率折线（纯内联 SVG，不引图表库） |

进入页面加载一次，页内有「刷新」按钮，切换数据目录会自动重载；**不做实时监听**（与文件监听解耦，避免常驻 IO）。

### 新增只读聚合命令 `get_insights`

Tauri 侧新增 `insights.rs`（聚合）+ `timestamps.rs`（最小 UTC 时间解析），命令 `get_insights` 一次扫描
`tasks/*/task.json` 与每个任务的**最新一轮** `report-*.json`，只做**计数与求和**；比率、TopN、趋势补齐、
周历聚合全部由前端 `core/insights.ts` 的纯函数计算（可单测，且不把时区与展示逻辑塞进 Rust）。

扫描口径与「任务列表」**完全一致**：只认 `tasks/tsk_*` 与 `tasks/vfy_*`，其余目录一律跳过。

## 口径说明（看数前请先读）

- **日期按 UTC 切分**：按天桶取 `createdAt` 的前 10 个字符（即 UTC 日期）；界面已显式标注，不猜本地时区。
- **按周以周一为一周之始**（ISO-8601）；跨月、跨年的同一周会归并到一个桶。
- **「一次通过」= 成功且仅用 1 轮**（`succeeded` 且 `roundsUsed <= 1`）。
- **「返修率」= 该桶内 `roundsUsed > 1` 的任务数 / 该桶任务总数**。
- **只统计每个任务的最新一轮报告**（优先快照上的 `reportRound`，否则取目录里最大的 `report-<轮次>.json`）。
  因此「返修后才成功」的任务，其**更早一轮的失败项不会进入归因聚合**——这是有意的口径。
- **平均验收耗时**只统计报告里 `startedAt` / `finishedAt` **都能解析**的轮次；解析失败的报告不进分母，**不编造时间**。
- **分母为 0 一律显示 `—`**，不显示 0%（不编造）。
- **只读**：本页与后端命令**不写任何业务数据**，不提供删除 / 清理入口；解析失败的报告如实计入「解析失败 N 份」。

## 边界（本批次没做什么）

按计划分三批交付，本版**只含第一批**：

| 功能 | 落在哪一批 |
|---|---|
| A4 多任务对比、A7 结构化筛选增强、A8a 命令面板 | `0.1.1-beta.2` |
| A5 基线漂移视图、A6 状态跃迁甘特、A9 磁盘占用统计、A8b 深链 `tianshu://task/<id>` | `0.1.1-beta.3` |

## 升级说明

- 本版**只新增只读视图与只读命令**，不改动既有界面与交互；任务列表、事件流、原始日志、验收报告、
  搜索 / 导出、更新检查均**行为不变**。
- 更新路径与 0.1.0 共用同一份 `latest.json` / `latest-gitee.json`，按语义版本号比大小，
  `0.1.1-beta.1 > 0.1.0`，因此从正式版直接升级到本预发布版是受支持的路径。
