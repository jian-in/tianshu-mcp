# 日志台 0.1.1-beta.2 — 结构化筛选 / 多任务对比 / 命令面板

> 完整变更记录见 [CHANGELOG](../CHANGELOG.md)；功能文档见 [docs/gui-log-viewer.md](gui-log-viewer.md)。

这是 0.1.1 线的**第二个预发布版**，交付「洞察」计划的第二批：**A4 多任务对比、A7 结构化筛选增强、A8a 命令面板与快捷键**。
三项**全部为前端主导的只读增强**，不新增 Tauri 插件、不改协议注册。

---

## 本次新增

### A7 结构化筛选增强（概览页筛选浮层）

筛选条件由 7 项扩为 11 项，新增四项**结构化**维度（口径与任务快照字段**逐字对应**）：

| 新筛选项 | 口径 |
|---|---|
| 错误类型 `errorType` | 精确匹配 `task.errorType`；选项来自当前任务集合的**分面**，不硬编码枚举 |
| 干跑 `dryRun` | 精确匹配 `task.dryRun`（全部 / 是 / 否 三态） |
| 返修 `reworked` | `是` = `roundsUsed > 1`；`否` = `roundsUsed <= 1`（**1 轮不算返修**） |
| 视觉验收 `hasVisual` | `是` = 存在 `report-<轮次>.html` 产物 |

Rust 侧 `TaskFilter`（`models.rs`）新增同名字段，`scanner.rs` 的 `matches_filter` 与前端 `core/filter.ts` 的
`filterTasks` **保持逐行同口径**（两处都改了，任一处漂移都会被单测与真机预览发现）；新增字段全部 `#[serde(default)]`，
旧调用方不传也不会失败。

### A4 多任务对比（洞察页 · 新增「任务对比」子分区）

- **左侧**：任务选择列表（复用既有任务集合 + 关键字过滤），勾选上限 **4 个**；超出时给出**明确提示**，
  **不静默顶替**已勾选项。
- **右侧**：指标矩阵，列为任务、行为指标 —— 状态 / Agent / 项目 / 已用轮次 / 验收耗时 / 改动行数（+ / -）/
  改动文件数 / 最新报告判定 / 失败检查项 / 错误类型 / 结论说明；轮次与耗时两行会标注**横向最优**。
- **报告按需拉取**：勾选时才读该任务最新一轮 `report-<轮次>.json`（优先快照的 `reportRound`），
  结果按 `taskId` 缓存，**已取过不重复请求**；切换数据目录会清空勾选与缓存。
- **缺失一律显示 `—`**：无报告时判定 / 改动统计留空，耗时回退任务快照起止（`createdAt → finishedAt`），
  两者都不可解析则如实留空——**不编造时长、不编造赢家**。

### A8a 命令面板与快捷键

- **`Ctrl/Cmd + K`** 打开命令面板（侧栏也新增了常驻入口），输入即**子序列模糊匹配**，
  `↑` `↓` 移动、`Enter` 执行、`Esc` 关闭；面板打开时**不触发**其他全局快捷键。
- 命令来源全部复用既有数据与动作：跳任务列表 / 洞察 / 运行日志 / MCP 能力、跨任务全局搜索、打开设置、
  **切换到某个数据目录**（当前目录带标注）、**直接打开某个任务**（上限 50 条，避免超长列表）。
- **`Ctrl/Cmd + R`** 刷新任务列表（已 `preventDefault`，不会触发 webview 重载）；
  带 `Alt` / `Shift` 的组合一律不拦截（不劫持 `Ctrl+Shift+R` 这类系统 / 浏览器组合）。

## 口径说明

- **筛选项不设默认值**：全部为「不限」；筛选结果由后端（桌面运行时）与前端各过滤一次，**两边同口径**，
  因此本地预览（mock）下的筛选行为与桌面端一致。
- **对比只读**：对比页不写任何业务数据，只读 `task.json` 与 `report-*.json`；不提供删除 / 清理入口。
- **对比「最优」仅在存在可比数值时标注**：全部缺失时不标注任何一项（不编造赢家）。
- **命令面板不新增写操作**：所有命令都跳到既有页面或既有只读动作，没有新增副作用。

  搜索 / 导出、更新检查、洞察页既有三个分区均**行为不变**。

  `0.1.1-beta.2 > 0.1.1-beta.1`，可直接从任一更早版本升级。
